Lock-screen guard — test pages

Open each page in a normal tab with the extension loaded. Scenario IDs match MANUAL_TEST_SCENARIOS.md. Pages must be served over HTTP (npm run serve); opening them from file:// produces opaque blob:null URLs.

Malicious — expected: tab is replaced by the warning page

PageWhat it does
malicious.htmlReference attack sample: self-opening blob lock screen, blocks right-click/keys, beforeunload.
mal-apple-no-phoneApple-themed, no phone number, legacy onkeydown/keyCode trapping.
mal-delayedNeutral placeholder for 2 s, then the lock screen. Click it during the first 2 s to test the "Leave site?" disarm.
mal-new-tab-clickCopies the benign arrival: click → window.open(blob) in a new tab.
mal-anchor-clickLaunches via a script-clicked <a>.
mal-no-trapsBlatant lock screen with no trapping code, self-opened.
mal-fullscreen-keylockBonus layer. Click "Open player", then click the lock screen: it requests full screen + Keyboard Lock.
mal-history-floodBonus layer. Click "Continue": floods history to break Back.
mal-alert-loopBonus layer. Click "Continue": endless alert() loop. Dismiss the first dialog.
